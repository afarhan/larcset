# larcset
LARCSet is an all analog inexpensive HF Radio.
It can be built from the pcb files of the project or ordered from hfsignals.com.
The larcset manual included here is usually dated. the latest is available from https://docs.google.com/document/d/10ynzuAaJK4nDdzysoZir7oInXb_Ld2hYF73WAQHt6xs/edit?usp=sharing
